# Logos das marcas

Coloque aqui um PNG por marca (fundo transparente, quadrado de preferência; aparece a 18 px).
O nome do arquivo tem que ser exatamente um destes:

acura.png, astonmartin.png, audi.png, bmw.png, cadillac.png, chevrolet.png, corvette.png, dallara.png,
ferrari.png, ford.png, ginetta.png, honda.png, hyundai.png, kia.png, lamborghini.png,
ligier.png, lotus.png, mazda.png, mclaren.png, mercedes.png, mini.png, nissan.png,
oreca.png, porsche.png, radical.png, renault.png, toyota.png, volkswagen.png

Marca sem arquivo aqui usa o ícone monocromático (simple-icons) ou a sigla em texto.
Depois de colocar um arquivo, basta F5 no dashboard. A lista de marcas está em
`MAKES` em `pitwall/engine.py` (prefixo do `CarPath` do iRacing → nome do arquivo).

Os PNGs desta pasta ficam fora do git (.gitignore): logos são marcas registradas.
Origem dos atuais: carlogos.org (/car-logos/<marca>-logo.png);
mclaren.png: símbolo (speedmark) fornecido pelo Caio.
